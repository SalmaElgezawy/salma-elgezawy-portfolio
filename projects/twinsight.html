TwinSight

An end-to-end predictive-maintenance concept combining sensing, signal processing, machine learning, remaining-useful-life estimation, and a Unity-based Digital Twin.

Predictive MaintenanceIndustrial AIIoTDigital Twin

The Problem

Industrial motors are critical assets, while reactive maintenance waits for faults to become costly and scheduled maintenance can replace components too early. TwinSight explores a more informed approach by combining live sensing, signal analysis, machine learning, remaining-useful-life estimation, and Digital Twin visualization.

The Approach

  • Industrial sensor telemetry and condition monitoring around an induction motor.
  • Signal processing with FFT-based analysis, Welch spectral analysis, Hilbert envelope analysis, and overlapping windows.
  • Feature engineering using RMS, Crest Factor, ISO Velocity, harmonics, harmonic ratios, bearing-envelope features, electrical measurements, and thermal information.
  • HistGradientBoostingClassifier for four mechanical states: Nominal, Unbalance, Misalignment, and Combined.
  • Unity-based Digital Twin for live visualization, fault-state exploration, and what-if scenarios.
  • FastAPI, MQTT, REST APIs, and PostgreSQL/time-series data handling for system integration.

Technical Decisions

  • Grouped validation was used to reduce recording-level leakage.
  • RobustScaler was used for resilient feature scaling.
  • GridSearchCV supported structured hyperparameter tuning.
  • The project treats signal processing, modeling, and system integration as one connected engineering workflow.

Results

The final mechanical-fault classifier achieved 90% Macro F1 across the four target classes.

Why It Matters

TwinSight demonstrates how sensor data, physical signals, machine learning, and interactive visualization can be combined into a practical predictive-maintenance workflow for industrial assets.
