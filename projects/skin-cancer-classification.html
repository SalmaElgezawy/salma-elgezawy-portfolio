Skin Cancer Classification

A research-oriented multimodal classification prototype combining dermatoscopic imagery with tabular metadata across seven lesion classes.

Deep LearningComputer VisionMultimodal MLMedical AI Research

The Problem

Dermatoscopic classification is challenging because visual patterns can be subtle, class distributions can be imbalanced, and useful context may also exist in metadata.

The Approach

  • HAM10000 dataset with seven lesion classes.
  • Image preprocessing, augmentation, class-imbalance handling, and exploratory analysis.
  • CNN-based visual branch combined with a tabular metadata branch.
  • Multimodal feature fusion before classification.
  • Flask interface for image upload and prediction.

Technical Decisions

  • The project combines visual and tabular information instead of relying on images alone.
  • Data augmentation and resampling address limited and imbalanced class representation.
  • The application is presented strictly as a research/educational prototype, not a clinical diagnostic system.

Results

The project demonstrates multimodal deep learning, image classification, class-imbalance handling, and application integration.

Why It Matters

It provides a concrete example of combining heterogeneous data modalities in a sensitive classification domain while keeping claims appropriately limited.
