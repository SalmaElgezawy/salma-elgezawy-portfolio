AI-Powered Predictive Maintenance for Industrial Motors

A rotating-machinery fault-classification project using vibration signals, engineered spectral features, deep learning, and physics-informed modeling ideas.

Predictive MaintenanceSignal ProcessingPhysics-Informed MLFault Classification

The Problem

Industrial vibration data contains rich fault signatures, but those signatures can be difficult to separate without careful signal processing and modeling. This project explores a modeling pipeline that uses both learned and engineered representations.

The Approach

  • Vibration-signal preprocessing and normalization.
  • FFT-based feature extraction and rotational harmonics.
  • Statistical features including RMS, kurtosis, skewness, and crest factor.
  • CNN-based representation learning combined with physics-informed ideas.
  • Evaluation across normal operation, imbalance, misalignment, and bearing-fault conditions.

Technical Decisions

  • Spectral and statistical features were used to preserve physically meaningful information.
  • The modeling pipeline combines data-driven learning with engineering knowledge instead of treating raw vibration as arbitrary input.
  • The MAFAULDA dataset provides a controlled benchmark for machinery-fault classification.

Results

The project achieved 98% overall classification accuracy.

Why It Matters

The project demonstrates how vibration analysis and machine learning can support automated identification of mechanical fault conditions in rotating machinery.
