Resume Screening System

An NLP pipeline that cleans, represents, augments, and classifies resumes into job categories, with a Streamlit interface for document upload.

NLPText ClassificationMachine LearningData Analysis

The Problem

Large collections of resumes contain unstructured text that can be difficult to organize manually. This project explores automated categorization as an initial document-routing task.

The Approach

  • Text cleaning, normalization, stopword handling, and lemmatization.
  • Exploratory text analysis and category-distribution review.
  • WordNet-based synonym augmentation to reduce class imbalance.
  • TF-IDF representation with LightGBM, XGBoost, and Random Forest comparisons.
  • Streamlit interface for PDF upload, text extraction, and category prediction.

Technical Decisions

  • The project is framed as categorization and organization rather than autonomous hiring.
  • Data augmentation was used to strengthen underrepresented categories.
  • Multiple tree-based models were compared before selecting LightGBM for the application.

Results

The final application supports resume upload and categorization across 24 job classes.

Why It Matters

The project demonstrates how NLP can transform unstructured resumes into structured categories that are easier to organize and review.
