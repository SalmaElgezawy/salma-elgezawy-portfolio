Weather Forecasting

A practical forecasting project covering exploratory analysis, stationarity, seasonality, outlier handling, Prophet modeling, and interactive visualization.

Time SeriesForecastingData AnalysisProphet

The Problem

Weather data combines trend, seasonality, noise, and variable-specific behavior. This project explores a complete analysis and forecasting workflow rather than treating forecasting as a single model call.

The Approach

  • Historical Delhi weather data for temperature, humidity, wind speed, and atmospheric pressure.
  • Time-series visualization, correlations, boxplots, stationarity analysis, seasonal decomposition, ACF/PACF exploration, and moving averages.
  • IQR-based outlier handling.
  • Separate Prophet models for individual weather variables.
  • Interactive Streamlit interface for forecast exploration.

Technical Decisions

  • EDA and stationarity checks were used to understand the temporal structure before forecasting.
  • Separate models allow each variable to retain its own time-series behavior.
  • The interface focuses on making forecasts easier to inspect rather than hiding the analytical workflow.

Results

The project delivers an end-to-end time-series analysis and interactive forecasting workflow.

Why It Matters

It demonstrates practical forecasting, temporal data exploration, and user-facing visualization in one project.
