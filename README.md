# Salma Elgezawy Portfolio

Static multi-page portfolio website.

## Open locally
Open `index.html` in any modern browser.

## Replace the portrait
Search `index.html` for the `.portrait` element. You can replace the placeholder with:
`<img src="assets/portrait.jpg" alt="Salma Elgezawy">`
and add CSS: `.portrait img{width:100%;height:100%;object-fit:cover}`

## Add project evidence
Each case-study page contains labeled visual placeholders. Replace them with real `<img>` / `<video>` elements as your media becomes available.

## Deploy for free
This folder can be hosted on GitHub Pages, Netlify, Cloudflare Pages, or any static host.
